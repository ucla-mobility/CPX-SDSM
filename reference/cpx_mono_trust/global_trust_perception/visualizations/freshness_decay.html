Feature explanation

Freshness is applied as a per-message multiplier \( F = \max\!\left(F_{\text{floor}},\ \rho^{\ \max(0,\ \delta t - \text{grace})}\right) \) (Su, Jin, Song 2024, Eq. 1: \(w[n] = \rho^{t - t_n}\), with a grace window added). \(\rho\) is a directly hand-tuned decay-per-second factor, not derived from the gate threshold.

Formula parameters (top grid)

Fresh grace (ms)
The window in which a message counts as fully fresh (\(F = 1\)). Any latency at or below this is "free"; decay only starts once you cross it. Default 40 ms.
Decay rate ρ
The per-second decay base: \(\rho = 0.5\) means \(F\) halves every second of latency past the grace window. Set directly, the same as the paper's \(\rho\) — not derived from any gate threshold. Default 0.50.
F floor
The lower bound \(F\) can never fall below, no matter how stale the message. Default 0.5.

Message inputs (middle panel)

Send-to-receive (ms)
\(\delta t\) for this specific message: how long it took to travel from sender to receiver. This is the input that actually determines \(F\) for a given message; it's independent of the formula parameters above.
Reputation
The sender's existing reputation score before this message's freshness penalty is applied.

Live stats

F for this message
The freshness score computed from the current \(\delta t\) and the three formula parameters, using \( F = \max\!\left(F_{\text{floor}},\ \rho^{\ \max(0,\ \delta t - \text{grace})}\right) \).
Reputation (unchanged)
What the sender's reputation would be if freshness weren't a factor at all — i.e., just the raw number you set.
Reputation × F
The actual updated reputation after the freshness penalty is applied. Since \(F \le 1\), this can only be less than or equal to the unchanged value.
