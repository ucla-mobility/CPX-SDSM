The equations

1. Signed step change — how much reputation moved since last step (positive = it fell, negative = it rose):

\[ d_t = R_{t-1} - R_t \]

2. Normalized drop — clip to \([0,1]\), so gains become zero and only falls count; the dead-zone \(\epsilon\) additionally ignores any drop smaller than \(\epsilon\,D_{\text{range}}\):

\[ \tilde d_t = \operatorname{clip}\!\left(\frac{d_t}{D_{\text{range}}} - \epsilon,\ 0,\ 1\right) \]

3. Persistence channel — a normalized leaky EMA (bounded in \([0,1]\)) that rises under sustained drops and bleeds off when they stop:

\[ \text{risk}^L_t = \beta_L\,\text{risk}^L_{t-1} + (1-\beta_L)\,\tilde d_t^{\,\alpha} \]

3a. Memory is set in real time, not as a raw \(\beta_L\). Pick a half-life \(T_{1/2}\); at \(f\) frames/sec that is \(N_{1/2}=f\,T_{1/2}\) frames, and \(\beta_L\) is derived so the accumulator halves over exactly that span:

\[ \beta_L = 2^{-1/N_{1/2}}, \qquad N_{1/2} = f\cdot T_{1/2} \]

The soft memory span (not a hard window) is \(N_{\text{eff}} = \tfrac{1}{1-\beta_L} \approx 1.44\,N_{1/2}\). This explorer fixes \(f=25\) fps and lets \(T_{1/2}\) run from a few frames up to 1 hour (90 000 frames) — a range a raw \(\beta_L\) slider can't resolve (an hour-long half-life is \(\beta_L\approx0.9999923\)).

4. Recent-severity channel — a normalized weighted average of the last \(K\) drops:

\[ \text{risk}^r_t = \frac{\sum_{k=0}^{K-1} \beta^{k}\,\tilde d_{t-k}^{\,\alpha}}{\sum_{k=0}^{K-1} \beta^{k}} \]

Keep \(K\) long enough that the window isn't decorative: \(K \gtrsim 3/(1-\beta)\) (e.g. \(\beta\approx0.98,\ K\approx150\)).

5. The weight — combine both channels, floored so it can't overpunish:

\[ V_t = \operatorname{clip}\!\left(1 - \lambda_r\,(\text{risk}^r_t)^{1/\alpha} - \lambda_L\,(\text{risk}^L_t)^{1/\alpha},\ V_{\text{floor}},\ 1\right) \]

\(\lambda_L\) is anchored to a duty cycle you consider intolerable: if an attacker is "bad" a fraction \(\delta_{\text{bad}}\) of frames at severity \(c\) and you want its weight driven to \(V_{\text{target}}\), then \(\lambda_L = (1-V_{\text{target}})/(\delta_{\text{bad}}\cdot c)^{1/\alpha}\). The default here uses \(\delta_{\text{bad}}=0.30,\ c=1,\ V_{\text{target}}=0.5\ (\alpha=1)\Rightarrow \lambda_L\approx1.67\): an attacker bad 30% of the time is pulled to \(V=0.5\).

6. Final reputation:

\[ \boxed{\,R_t = R^{\text{calc}}_t \cdot F \cdot V_t\,} \]

Optional machinery (not simulated here)

These only matter if you persist \(\text{risk}^L\) per-ID across separate encounters; this single continuous trajectory exercises neither, so they're documented, not run. Cold-start debiasing during an ID's warm-up (\(t\) = frames observed for that ID): \(\widehat{\text{risk}}^L_t = \text{risk}^L_t/(1-\beta_L^{\,t})\). Gap handling on re-acquisition after an absence of \(\Delta t_{\text{gap}}\) seconds, applied once at rejoin: \(\text{risk}^L_{\text{rejoin}} = \beta_L^{\,f\,\Delta t_{\text{gap}}}\,\text{risk}^L_{\text{last}}\).

Two derived quantities worth keeping in mind

These aren't computed each step — they're properties of your parameter choices that tell you how the system behaves:

\[ S_L = (1-\beta_L)^{-1/\alpha} \qquad \text{(persistence ÷ single selectivity)} \]

The ratio by which a sustained slide is punished harder than a lone dip of the same step-size. The step-3 normalization leaves this ratio intact — a single drop contributes \((1-\beta_L)\), a sustained one saturates at \(1\). At \(\beta_L=0.95,\ \alpha=1\) it's \(20\times\).

\[ m_{1/2} = \frac{\alpha \ln 2}{-\ln \beta_L} \qquad \text{(rebound half-life, in steps)} \]

How many steps it takes the penalty to halve after drops stop; at \(\alpha=1\) this equals \(N_{1/2}\) exactly. Raising \(T_{1/2}\) improves \(S_L\) but lengthens \(m_{1/2}\) — that's the one real trade-off in the whole design.
