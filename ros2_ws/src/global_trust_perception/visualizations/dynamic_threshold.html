Dynamic threshold

The gate admits an agent when \(R_{\text{eff}} \geq \tau(R_{\text{eff}})\). Because \(\tau\) is strictly decreasing in R, this is equivalent to \(R_{\text{eff}} \geq R^*\), the unique fixed point where the curves cross.

\[ \tau(R) = \tau_{\min} + (\tau_{\max} - \tau_{\min})(1 - R^{\gamma}) \]

\(\gamma > 1\) bends the curve so that low-reputation agents face a disproportionately high bar. \(\gamma = 1\) is a straight line. \(\gamma < 1\) is lenient at the bottom.

Every variable

SymbolNameWhat it does
\(\tau_{\min}\)threshold floorThe threshold even a perfectly reputable agent must clear (default 0.30). Prevents trust inflation
\(\tau_{\max}\)threshold ceilingThe threshold for a zero-reputation stranger (default 0.90). Sets how hard it is to get in from cold
\(\gamma\)strictness exponentCurve shape. \(>1\) = strict on low-R agents, lenient once trusted. \(=1\) = linear. \(<1\) = lenient throughout
\(R^*\)fixed pointThe crossover where \(R = \tau(R)\): the minimum reputation to pass the gate (found by bisection)
