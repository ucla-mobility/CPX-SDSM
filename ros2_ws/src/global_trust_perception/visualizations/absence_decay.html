Absence-gap decay

When a previously seen agent re-appears after a gap, its stored reputation is decayed toward the neutral baseline before starting the new session. This is a one-shot correction applied at reseed time — not each frame.

A grace window (default 3 days) protects against brief offline periods: no decay is applied until the gap exceeds that threshold.

\[ \text{eff} = \max(0,\ \Delta t - \text{grace}) \]
\[ R_{\text{seeded}} = \text{baseline} + (R_{\text{last}} - \text{baseline})\,e^{-\text{eff}\,/\,\tau} \]

Downward-only: if \(R_{\text{last}} \leq \text{baseline}\), the agent returns at its stored value unchanged. Silence must not reward a distrusted agent by pulling it toward neutral.

Relationship to persistence penalty

Absence decay modifies the stored reputation used to seed the next session (applied once at reseed). The persistence penalty weight \(V\), by contrast, is a gate-only multiplier applied each frame that never writes back to stored \(R\). They operate at different phases: absence decay at reseed time (once per gap), \(V\) at every frame.
