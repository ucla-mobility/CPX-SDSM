What this is

The actual recorded reputation trajectory for agent 2 (the vehicle), as judged by ego 1 (the infrastructure), read from ego 1's own historical_reputations_1.db -- not a simulation. The trusted zone is the current fixed gate threshold, R = 0.6, not the dynamic \(\tau(R)\) formula reputation_update.html and dynamic_threshold.html illustrate.

This page never touches the database itself: a companion script, scripts/make_reputation_history_viz.py, reads it and writes reputation_history_data.js, which this page loads as a plain script tag so it still opens with no server, over file://. Rerun the script after a demo run to refresh the chart -- reloading this page alone will not.
