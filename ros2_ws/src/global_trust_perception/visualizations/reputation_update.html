Reputation update

Each frame with data produces a score \(S \in [-1,1]\) based on correct vs incorrect observations, and reputation moves by \(\delta \cdot S\).

\[ S_t = \frac{C - I}{N},\qquad R_{t+1} = \operatorname{clip}(R_t + \delta \cdot S_t,\ 0,\ 1) \]

When the agent sends nothing (\(N=0\)), reputation drifts toward baseline rather than freezing — preventing stale reputations from persisting indefinitely:

\[ R_{t+1} = R_t + \lambda({\text{baseline}} - R_t) \quad \text{(empty frame)} \]

Every variable

SymbolNameWhat it does
\(C,\,I\)correct / incorrectCounts of observations the neighbour got right vs wrong this frame
\(N\)total observationsC + I (or more); normalises S to [-1,1]
\(S_t\)frame scoreNet correctness fraction this frame; +1 = perfect, -1 = all wrong
\(\delta\)step sizeHow much R moves per frame (default 0.10). Larger = faster trust building and destruction
\(\lambda\)decay rateDrift-toward-baseline rate on empty frames (default 0.003 per frame)
baselineneutral RThe value empty-frame decay aims at (default 0.5)
